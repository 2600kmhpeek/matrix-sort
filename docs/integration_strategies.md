# Сравнительный анализ стратегий интеграции

| Стратегия | Преимущества | Недостатки | Когда применять |
|-----------|--------------|------------|-----------------|
| Нисходящая | Ранняя проверка архитектуры верхнего уровня | Нужны заглушки; нижние модули тестируются поздно | Сложная логика управления |
| Восходящая | Не нужны заглушки; базовые модули проверены рано | Система целиком видна поздно; нужны драйверы | Важны низкоуровневые библиотеки |
| Сэндвич | Параллельная работа сверху и снизу | Сложная организация | Крупные многоуровневые системы |
| Риск-ориентированная | Рискованное проверяется первым | Нужна оценка рисков | Есть неопределённые или критичные модули |
| Функционально-ориентированная | Рабочая функция системы появляется рано, удобна для демонстрации | Модули могут дорабатываться несколько раз | Небольшие проекты с понятными функциями |
| Т-образная | Сквозной вертикальный срез проверяет все слои | Остальное остаётся недоделанным дольше | Новые системы с неясной архитектурой |

Для МатрСорт-16 выбрана функционально-ориентированная стратегия: у системы одна ключевая функция (сортировка матрицы), и её удобно собрать сквозным путём ввод -> обработка -> вывод.

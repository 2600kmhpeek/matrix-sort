# Архитектура проекта «МатрСорт-16»

## Общее описание

Консольное приложение на Python. Программа последовательно запрашивает
размерность и элементы матрицы, сортирует все элементы по убыванию
(обход по строкам) и выводит результат. Логика разделена на три слоя:
ввод, обработка и вывод. Обработка не зависит от ввода-вывода,
поэтому тестируется отдельно.

## Модули (`src/matrix_sort.py`)

| Функция | Слой | Назначение |
|---------|------|------------|
| `input_size(prompt)` | ввод | Возвращает положительное целое число, повторяя запрос при ошибке. |
| `input_matrix(m, n)` | ввод | Читает m строк по n вещественных чисел, проверяет тип и количество. |
| `sort_desc(matrix)` | обработка | Возвращает отсортированный по убыванию одномерный массив и матрицу m × n. |
| `format_matrix(matrix)` | вывод | Форматирует массив с `PRECISION` знаками после запятой. |
| `main()` | управление | Цикл «ввод → обработка → вывод → продолжить?». |

## Поток данных

```
ввод m, n → ввод матрицы → flatten() (обход по строкам)
          → np.sort()[::-1] (по убыванию) → reshape(m, n) → вывод
```

## Принятые решения

- Сортировка вынесена в чистую функцию `sort_desc` для модульного тестирования.
- Используется NumPy: `flatten`, `sort`, `reshape` напрямую соответствуют шагам алгоритма.
- Точность вывода задаётся константой `PRECISION = 3` (требование ТЗ, п. 4.1.1).
- Зависимости перечислены в `requirements.txt`, проверки выполняются в CI.

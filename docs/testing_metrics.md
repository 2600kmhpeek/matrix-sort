## 2. Плотность дефектов

Исходный код: 241 физическая строка в `src/*.py`.

```
Плотность дефектов = число дефектов / строки кода × 1000
                   = 2 / 241 × 1000 ≈ 8,3 дефекта на 1000 строк
```

Оба дефекта найдены на этапе тестирования (до выпуска версии), поэтому
плотность дефектов эксплуатации равна нулю.

## 7. Выводы по метрикам

1. Покрытие 90 % превышает целевые 70 % и порог CI 80 %.
2. Оба найденных дефекта относились к граничным случаям (размер вывода,
   структура ответа), что подтверждает ценность анализа граничных значений и
   тестирования отказов.
3. Плотность 8,3 дефекта на 1000 строк для учебного проекта приемлема:
   дефекты найдены до эксплуатации и закрыты тестами.
4. Полный прогон занимает менее секунды, поэтому регрессионные тесты можно
   запускать на каждый коммит без замедления работы.

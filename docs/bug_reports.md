# Баг-репорты

## Баг-репорт №1

**Заголовок:** вывод матрицы размером более 1000 элементов обрезается многоточием.

**Проект / модуль:** МатрСорт-16, `src/matrix_sort.py`, функция `format_matrix`.

**Описание:** `np.array2string` по умолчанию включает режим краткого вывода
(`threshold = 1000`). Если в матрице или в плоском списке больше 1000
элементов, вместо значений печатается многоточие. Пользователь видит неполный
результат сортировки, хотя расчёт выполнен верно.

**Шаги воспроизведения:**

1. Запустить `python -c "import numpy as np; from src.matrix_sort import format_matrix; print(format_matrix(np.arange(1200.0)))"`.
2. Найти в выводе `...`.
3. Убедиться, что количество напечатанных чисел меньше 1200.

**Ожидаемое поведение:** напечатаны все 1200 элементов с тремя знаками после
запятой.

**Фактическое поведение:** массив сокращён, присутствует `...`.

**Окружение:** Python 3.14.7, NumPy 2.x, Linux.

**Тяжесть:** средняя. **Приоритет:** высокий. **Статус:** исправлено.

**Причина:** не задан параметр `threshold` при вызове `np.array2string`.

**Исправление:** в `format_matrix` добавлен `threshold=sys.maxsize`; импорт
`sys` добавлен в модуль.

**Регрессионные тесты:** `test_large_matrix_output_is_not_truncated`,
`test_long_flat_output_is_not_truncated`.

## Баг-репорт №2

**Заголовок:** клиент падает с `AttributeError`/`KeyError` при некорректной
структуре ответа сервиса.

**Проект / модуль:** МатрСорт-16, `src/client.py`, функция `_parse_response`.

**Описание:** клиент проверяет только код HTTP и поле `status`, но не тип
JSON-тела и наличие обязательных полей. Если сервис вернул JSON-массив,
`null` или объект без `sorted_flat`/`sorted_matrix`, возникает необработанное
исключение `AttributeError` или `KeyError` вместо `IntegrationError`.
Приложение `integrated_app` перехватывает только `IntegrationError`, поэтому
падает с трассировкой.

**Шаги воспроизведения:**

1. Подменить `requests.post` ответом с телом `[1, 2, 3]` (или `{"status": "ok"}`).
2. Вызвать `client.sort_remote([[1]], retries=0)`.
3. Получить `AttributeError: 'list' object has no attribute 'get'`
   (или `KeyError: 'sorted_flat'`).

**Ожидаемое поведение:** `IntegrationError` с понятным сообщением, приложение
выводит «Ошибка интеграции» и продолжает работу.

**Фактическое поведение:** необработанные `AttributeError`/`KeyError`.

**Окружение:** Python 3.14.7, requests 2.x, Linux.

**Тяжесть:** высокая (нарушена обработка отказов интеграции).
**Приоритет:** высокий. **Статус:** исправлено.

**Причина:** отсутствует проверка `isinstance(body, dict)` и обработка
отсутствующих ключей.

**Исправление:** в `_parse_response` добавлена проверка типа тела и
`try/except KeyError` с преобразованием в `IntegrationError`.

**Регрессионные тесты:** `test_client_rejects_non_object_json`,
`test_client_rejects_response_without_fields`.

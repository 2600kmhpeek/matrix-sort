# Инспекция кода интеграции

Инструмент: flake8 (`flake8 src tests --max-line-length=100`), запускается в CI.
Результат: замечаний нет (вставьте фактический вывод).

## Ревью

| № | Серьёзность | Замечание | Статус |
|---|-------------|-----------|--------|
| 1 | Высокая | Сервис должен проверять данные независимо от клиента (nan, inf, bool, рваные строки) | Исправлено: validate_matrix |
| 2 | Средняя | numpy-массивы не сериализуются в JSON | Исправлено: tolist() |
| 3 | Средняя | Нет повторных попыток и таймаута при вызове сервиса | Исправлено: timeout и retries в sort_remote |
| 4 | Низкая | Сервис слушает только 127.0.0.1, нет аутентификации | Принято: учебный проект |
| 5 | Низкая | Нет ограничения на размер матрицы | Исправлено: MAX_ELEMENTS |

Инструмент: flake8 (`flake8 src tests --max-line-length=100`), запускается в CI.
Результат: замечаний нет.

| № | Серьёзность | Замечание | Статус |
|---|-------------|-----------|--------|
| 1 | Высокая | Сервис должен проверять данные независимо от клиента (nan, inf, bool, рваные строки) | Исправлено: validate_matrix |

## Инспекция кода тестирования (ЛР №4)

Инструмент: flake8 7.5.0 (pycodestyle 2.15.0, pyflakes 4.1.0, mccabe 0.7.0).

```bash
flake8 src tests --max-line-length=100 --statistics
```

Результат: вывод пуст, код возврата 0 — замечаний нет. Линтер также запускается
в GitHub Actions (workflow `Testing`) на каждый push и pull request.

### Проверенные критерии

| № | Критерий | Результат |
|---|----------|-----------|
| 1 | Длина строки не более 100 символов (E501) | нарушений нет |
| 2 | Нет неиспользуемых импортов (F401) | нарушений нет |
| 3 | Нет неопределённых имён (F821) | нарушений нет |
| 4 | Отступы и пустые строки (E1xx, E3xx) | нарушений нет |
| 5 | Пробелы в выражениях (E2xx) | нарушений нет |
| 6 | Имена переменных и функций в snake_case | соблюдается |
| 7 | Константы вынесены (`PRECISION`, `MAX_ELEMENTS`, `API_VERSION`) | соблюдается |
| 8 | Нет «голых» `except:` | соблюдается |
| 9 | Нет изменяемых значений по умолчанию | соблюдается |
| 10 | Докстринги у модулей и публичных функций | добавлены в `service.py`, `client.py`, `integrated_app.py` и тестах |

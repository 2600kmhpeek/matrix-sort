# Российские аналоги Git в Едином реестре российского ПО

Все перечисленные продукты построены на Git, поэтому команды `clone`, `commit`,
`push`, `merge` работают в них так же, как и на GitHub.

| Продукт (№ в реестре) | Назначение | Возможности | Преимущества | Ограничения |
|-----------------------|------------|-------------|--------------|-------------|
| GitFlic (№15861) | DevOps-платформа для хранения кода и совместной разработки, альтернатива GitLab | Репозитории, совместная работа, CI/CD; облачный и локальный варианты | Российская юрисдикция, можно развернуть на своих серверах | Меньше интеграций и сообщество меньше, чем у GitHub/GitLab |
| GitFlame (№21590) | Сервис хранения репозиториев с версионным контролем кода для разработчиков и DevOps | Хранение и версионирование кода на базе Git | Лёгкий старт, отечественное ПО | Набор функций уже, чем у крупных платформ |
| Gitlife Enterprise (№29396) | Платформа управления жизненным циклом проектов | Модуль «Код» на базе Git и другие модули (управление проектами) | Всё в одной платформе | Ориентирована на организации, избыточна для небольшого учебного проекта |
| Deckhouse Code (№27871) | Непрерывная разработка и управление жизненным циклом ПО | Хранение кода, CI/CD | Ориентация на корпоративное применение и безопасность | Требует развёртывания и сопровождения |
| EvaGit (в составе EvaTeam) | Система управления Git-репозиториями | Ветки, коммиты, pull request, код-ревью | Тесная связка с задачами EvaTeam | Работает как часть платформы EvaTeam |
| Mos.Hub (городской проект) | Городской репозиторий ПО с открытым кодом, аналог GitHub | Хостинг открытых проектов | Бесплатный хостинг для российских разработчиков | Узкая аудитория, ограниченный набор функций |

Сведения о номерах в реестре взяты из методических указаний к ЛР №2; актуальные данные
проверяются на https://reestr.digital.gov.ru/.

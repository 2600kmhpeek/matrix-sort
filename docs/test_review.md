# Ревью тестов

Ревью проведено автором проекта (Розанов А.С.) по чек-листу; замечания
исправлены до финального коммита.

## 1. Чек-лист

| № | Критерий | Результат |
|---|----------|-----------|
| 1 | Имена тестов описывают проверяемое поведение | соответствует |
| 2 | Тест проверяет одну ситуацию, причина падения понятна | соответствует |
| 3 | Тесты детерминированы (нет случайных данных без seed) | соответствует: `default_rng(42)` |
| 4 | Тесты изолированы (не зависят от порядка запуска) | соответствует: `monkeypatch`, фикстуры |
| 5 | Нет реальных сетевых вызовов в модульных тестах | соответствует: `requests.post` подменяется |
| 6 | Проверены граничные значения и отказы | соответствует |
| 7 | Параметризация вместо копирования тестов | соответствует: `@pytest.mark.parametrize` |
| 8 | Есть регрессионные тесты на исправленные дефекты | соответствует: `test_regression.py` |
| 9 | Тесты проходят flake8 | соответствует: 0 замечаний |
| 10 | Время прогона приемлемо | соответствует: 0,74 с |

# МатрСорт-16 — сортировка элементов матрицы по убыванию

## Назначение

Консольная программа на Python. Принимает от пользователя вещественную
матрицу размерности m × n, обходит её по строкам и выводит все элементы
в порядке убывания, а также матрицу той же размерности, заполненную
отсортированными значениями по строкам (вариант 16).

## Требования к окружению

- Python 3.10 или новее;
- библиотека NumPy;
- ОС Linux или Windows 7/10/11.

## Запуск (предварительная инструкция)

```bash
python src/matrix_sort.py
```

## Стратегия ветвления

В проекте используется упрощённый **Git Flow**:

| Ветка | Назначение |
|-------|------------|
| `main` | Стабильная версия. Каждый коммит слияния — готовый к сдаче релиз, на нём ставятся теги версий (`v0.1.0`). |
| `develop` | Интеграционная ветка. Сюда сливаются завершённые функции, здесь проверяется их совместная работа. |
| `feature/<имя>` | Короткоживущие ветки под одну задачу. Создаются от `develop` и в него же сливаются через `--no-ff`. |

Порядок работы: `feature/*` → `develop` → `main`. Прямые коммиты допускаются
только для мелких правок документации в `develop`.

**Почему так.** Проект учебный и небольшой, поэтому полный Git Flow с ветками
`release` и `hotfix` избыточен, а GitHub Flow (одна ветка `main`) не даёт
отдельной площадки для проверки изменений перед выпуском. Схема с `develop`
защищает `main` от неотлаженного кода и хорошо ложится на CI: проверки
запускаются при каждом push и pull request в обе основные ветки.
